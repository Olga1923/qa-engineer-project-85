## О Хекслете

[Хекслет](https://ru.hexlet.io/) — школа программирования: авторские программы обучения с практикой, поддержкой наставников и реальными проектами, которые остаются в резюме. Этот репозиторий — один из таких проектов.



## О тестируемом проекте

Codebattle — это онлайн-игра для программистов, в которой два игрока одновременно решают одну задачу на скорость. Во время игры участники могут видеть код друг друга, проверять решения с помощью тестов и общаться в чате.

Проект разработан сообществом Хекслета и распространяется с открытым исходным кодом.

Сайт приложения: https://codebattle.hexlet.io/

## Основные возможности

- Игра с другим пользователем, ботом или другом по специальной ссылке.
- Выбор уровня сложности и задачи.
- Поддержка русского и английского языков.
- Просмотр кода соперника и результатов тестирования во время игры.
- Наблюдение за играми других пользователей.
- Общение в игровом чате.
- Просмотр записей завершённых игр.
- Начисление очков и формирование рейтингов.

## Цель тестирования

Цель проекта — проверить работу приложения Codebattle в продакшене, выявить возможные ошибки и убедиться в корректной работе основных функций.

## Содержимое репозитория

- `README.md` — описание проекта и информация о репозитории.
- `requirements.yml` — функциональные, нефункциональные и неявные требования к приложению.
- `.github/workflows/hexlet-check.yml` — файл настройки автоматических проверок Хекслета.
- Другие файлы и материалы, добавляемые по мере выполнения заданий по тестированию.
